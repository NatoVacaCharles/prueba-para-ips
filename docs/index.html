// 02 — Pipeline CI/CD DevOps

Integración y Entrega Continua

El pipeline se activa automáticamente en cada push al repositorio. Compila, prueba, analiza calidad y despliega sin intervención manual.

📥
Push / PR
Código sube al repositorio
🔨
Build
mvn clean compile
🧪
Test
JUnit 5 + JaCoCo
🔍
Quality
Spotless + PMD
📊
Report
Burndown + Coverage
🚀
Deploy
GitHub Pages
ci.yml
Activo
Build + tests unitarios + cobertura JaCoCo + análisis PMD/Spotless. Se ejecuta en cada push y PR.
cd-pages.yml
Activo
Genera documentación del Sprint, ejecuta script de burndown y despliega todo en GitHub Pages automáticamente al mergear a main.
scrum-automation.yml
Activo
Auto-etiqueta issues nuevos, verifica que PRs tengan issue vinculado y genera reporte diario del estado del Sprint.
generate_burndown.py
Activo
Script Python que consulta la API de GitHub, calcula puntos restantes por día y genera el burndown chart en HTML con Chart.js.
